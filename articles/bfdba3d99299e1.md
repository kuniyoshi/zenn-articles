# 自分用アプリ
AI エージェントのコーディング能力は高いですよね。Go は書いたことなかったんですが、普通に Go のプロジェクトに参加できました。

そんな AI エージェントの力を使えば自分が欲しいものを自分用に作れることがわかったので私も作りました。下記が実際に作った macOS 用のアプリです。

| 名前                                          | 概要                                                         |
|-----------------------------------------------|--------------------------------------------------------------|
| [Tima](https://github.com/kuniyoshi/Tima)     | タイムボックスツールです。設定した時間が経ったら通知します。 |
| [EiKana](https://github.com/kuniyoshi/EiKana) | 文字入力ソースをステートレスに切り替えます。                 |
| [KeyHop](https://github.com/kuniyoshi/KeyHop) | キーボードショートカットでアプリを切り替えるランチャーです。 |

# Tima

Tima はタイムボックスツールです。私にはポモドーロテクニックが性に合っていて、以前は自作スクリプトと [Toggl Track](https://toggl.com) とを使っていました。Toggl では今やっている作業を宣言し、自作スクリプトの方では時間の経過を通知していました。

Tima はこれと同等の機能を持ちます。つまり

- 25 分後に通知し、その 5 分後にもう一度通知します。
- そして、今やっている作業を宣言する機能です。

以前使っていたスクリプトも載せておきます。`sleep` して `terminal-notifier` とサウンド再生するだけのものです。

```bash
#!/bin/bash
project="$1"
shift
title="$*"
log_file=~/logs/pomodoro.log
notification_interval_seconds=20
lock_file=/tmp/pomodoro.is_notifying
interval_lock_file=/tmp/pomodoro.is_in_interval

pomodoro_seconds=$((25 * 60))
pomodoro_interval_seconds=$((5 * 60))
started_at=$(date +%FT%T)

echo -e "$started_at\t$project\t$title" >>"$log_file"

#osascript -e 'tell application "Twitter"' -e '  set miniaturized of window 1 to true' -e 'end tell'

sleep "$pomodoro_seconds"

started_at=$(date +%s)
touch "$lock_file"

while [ -e "$lock_file" ]
do
    elapsed=$(($(date +%s) - started_at))

    terminal-notifier -title "START INTERVAL" \
        -message "$title - $project, elapsed: $elapsed" \
        -execute "rm $lock_file"

    play_utc_voice.sh

    sleep "$notification_interval_seconds"
done

#osascript -e 'tell application "slack"' -e '  set miniaturized of window 1 to false' -e 'end tell'

sleep "$pomodoro_interval_seconds"

started_at=$(date +%s)
touch "$interval_lock_file"

while [ -e "$interval_lock_file" ]
do
    elapsed=$(($(date +%s) - started_at))

    terminal-notifier -title "DONE POMODORO" \
        -message "$title - $project, elapsed: $elapsed" \
        -execute "rm $interval_lock_file"

    play_utc_voice.sh

    sleep "$notification_interval_seconds"
done
```

Tima の話にもどりますが、自分用に自作したことで痒い所に手が届くアプリになりました。

- OS がスリープになったらタイマーを止める (止め忘れ防止)
- キーボードショートカットで操作できるように
- 一日ごとのタイムボックスの数がわかるように

Toggl のときは時間を止め忘れて翌日に調整するということが発生していました。そういうことがよくあったので自動停止機能を追加しました。

# EiKana

EiKana は入力ソースの「ひらがな」、「英字」を切り替えます。デフォルトでも Ctrl-Space で切り替えられますが、Ctrl-Space の方は状態があるのが使いづらいです。つまり、今が「ひらがな」か「英字」かがわからないといけません。対して EiKana は状態に依存しません。たとえば、左 Ctrl で「英字」、右 Ctrl で「ひらがな」のように固定して切り替えられます。

以前は Karabiner-Elements を使っていましたが、macOS のバージョンが上がったときにしばらく使えない時期がありました。今は使えるようになっているようです。Karabiner-Elements は私がやりたいことに対して高機能すぎるので macOS のバージョンアップに対応しやすいように EiKana の機能だけ切り出して作りました。

# KeyHop

KeyHop はランチャーです。Spotlight も併用していますが、頻繁に使うには入力の手間が多いです。この手のランチャーは何種類か使ってきましたが OS の更新に伴って使えなくなっていきました。使えなくなる度に良さそうなのを探すのも面倒になっていたので自作するモチベーションになりました。

# 終わりに

キー入力の監視はセキュリティ的にも気になるところなので自作するのもいいと思います。これまでは自分でやるには学習時間がネックになっていたアプリたちですが AI エージェントのおかげで気軽に作れるようになりました。
